## Forecast app (Binance)

### Торговая стратегия (целевое описание)

Стратегия рассчитана на **среднесрочные** движения по **ликвидным** криптовалютам — в первую очередь **BTC** и **ETH**, на таймфрейме **4H**.

**Общая идея.** Вход только **по сторону текущего тренда**. Сделки **во флэте**, **против тренда** и в неопределённом контексте рынка **избегаются**.

#### Направление тренда (EMA 50 / EMA 200)

- **Long:** цена **выше EMA 200** и одновременно **EMA 50 > EMA 200**.

Сторона **short** (если включается в исполнение) задаётся **зеркально** в спецификации бота/исполнения.

#### Вход после пробоя + объём + RSI

- Вход после **пробоя максимума последних 20 свечей**, с **подтверждением объёмом**.
- Индикатор **RSI (14)** — **не входить**, если актив **перекуплен** (лонги в зонах перегрева пропускаются).

#### Риск и цели

- Волатильность — **ATR (14)**.
- **Стоп-лосс:** **`1.5 × ATR`** от точки входа.
- **Размер позиции:** так, чтобы **риск на сделку** был в коридоре **0.5–1%** депозита.
- **Цель:** **`2R`–`3R`**, альтернативно или дополнительно — **выход по trailing stop** (параметры трейлинга задаются правилами исполнения).

#### Почему стратегия удобна для автоматизации

Чётко формализованы **условия входа**, **выхода**, **риска** и **размера позиции** — правила воспроизводимы в коде без субъективных трактовок.

#### Ограничения

Стратегия **лучше всего работает в трендовых фазах**. В **флэте** возможны **ложные пробои**.

**Желательно** использовать **фильтр общего состояния рынка по BTC** (макроконтекст / режим рынка), чтобы снижать торговлю в неблагоприятные периоды.

> **Примечание по коду этого репозитория.** Сейчас в проекте также реализованы **прогноз по similarity / k‑NN**, **trade gate** и упрощённые бэктесты — они могут **частично пересекаться** с описанными выше правилами, но **не обязаны** совпадать с ними один в один без отдельной синхронизации логики. Ниже перечислены фактические возможности приложения.

**Возможности первой версии (техника проекта):**
- **Загрузка свечей**: скачивает исторические OHLCV с Binance через `ccxt`.
- **Сохранение в CSV**: кладёт файлы в `data/raw/`.
- **Загрузка в pandas**: читает CSV в `DataFrame`.
- **Индикаторы и признаки**: считает базовые индикаторы (`ta`) и формирует признаки.
- **Поиск похожих участков**: k-NN по окнам признаков (скользящие окна).
- **Вероятностный прогноз**: оценивает вероятность направления цены по похожим историческим участкам.
- **Простой бэктест**: walk-forward проверка сигналов по прогнозам и настройкам в `configs/config.yaml`.

### Установка

Рекомендуется создать виртуальное окружение (пример для macOS / Linux):

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установка зависимостей:

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

**TA-Lib (важно):**
- На macOS обычно нужно предварительно:

```bash
brew install ta-lib
```

- После этого `pip install TA-Lib` (уже есть в `requirements.txt`).

### Настройка ключей Binance

Создайте файл `.env` в корне проекта (рядом с `.env.example`):

```bash
cp .env.example .env
```

И заполните:

```text
BINANCE_API_KEY=ваш_ключ
BINANCE_API_SECRET=ваш_секрет
```

Без ключей приложение будет использовать публичные данные (если это позволяет Binance), но лучше указать ключи.

### Конфигурация

Основной конфиг: `configs/config.yaml`.

В нём можно задать:
- `symbol`: например `BTC/USDT`.
- `timeframe`: `1h`, `15m`, `4h` и т.п.
- `limit`: сколько баров качать.
- `use_futures`: `true` для Binance Futures USDT-M, `false` для spot.
- `similarity`: параметры окна, число соседей, горизонт прогноза.
- `backtest`: пороги для входа и транзакционные издержки.

### Запуск пайплайна

Из корня проекта:

```bash
python -m forecast.main --config configs/config.yaml
```

Пайплайн выполняет шаги:
1. Скачивает свечи с Binance.
2. Сохраняет в `data/raw/`.
3. Загружает в pandas.
4. Считает индикаторы.
5. Формирует признаки.
6. Находит похожие участки.
7. Выдаёт вероятность направления (вверх/вниз).
8. Прогоняет простой бэктест и выводит финальный equity.

### Веб-экран в браузере (FastAPI)

Чтобы открыть простой экран в браузере:

```bash
uvicorn forecast.api:app --reload
```

Затем зайдите в браузере на `http://127.0.0.1:8000/multi`.

Страница покажет:
- текущие вероятности `Prob up` / `Prob down`,
- последнюю цену `close`,
- количество сделок и финальный `equity` по бэктесту.

Каждое обновление страницы заново запускает пайплайн и пересчитывает прогноз.
